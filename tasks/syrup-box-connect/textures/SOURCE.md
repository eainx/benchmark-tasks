# bib-syrup-carton-print

Print artwork for a 5-gallon bag-in-box soda syrup carton (273 x 394 mm faces, 4 px/mm).

- Brand "Velmora" is invented for this benchmark; no real trademark is copied.
- Rendered by `make_textures.py` with Pillow from free system fonts:
  - Liberation Sans / Serif (SIL Open Font License 1.1)
  - DejaVu Sans / Sans Mono (Bitstream Vera licence)
- Barcode digits, lot code and nutrition values are illustrative.
- `textures/carton_front.png`: brand panel, product line, 5+1 mix badge, knock-out circle, THIS SIDE UP, recycle mark.
- `textures/carton_side.png`: brand panel, nutrition facts and ingredients, barcode, lot / best-by stamp, handling marks.
